# 早晚节目卡片与朗读优化 — 2026-09-21

Radio 首页按北京时间的生产日期与早晚时段显示汇总卡片。每天已有内容的早间、晚间各一张；不生成没有内容的占位节目。顶部日期、天气和刷新汇总卡已移除，四个板块保持不变。

卡片显示日期、星期、可播音频数量、总时长及待生成数量，默认收起单篇内容；“查看节目”保留文章详情入口，“播放整组”按组内发布时间从早到晚连续播放。已听状态不减少卡片总数。新增音频在应用内提示，可播数与总时长同步更新。Web 可见时每 30 秒检查一次、重新可见时检查；Android 每 30 秒及恢复前台时检查。静默检查不会替换当前播放队列，新节目可从更新后的卡片重新开始播放。这是应用内更新提示，不是应用退出后的系统推送。

## 分组与分页

`GET /api/items?edition_pages=true&page=N` 保持原 Item 数据格式，每页返回六个完整时段的全部条目；该模式不采用普通 item limit。普通 `/api/items` 行为不变。专门测试了一组 61 篇，不会被 50 条分页截断。

外驱任务使用已完成 agent job 的 `context.run_date` 和 `slot`（morning/evening），因此延迟生成音频不改变所属时段。通过现有 tags 传递 `radio:date:YYYY-MM-DD`、`radio:edition:morning|evening`，不改变 Flutter Rust Bridge 类型。旧自驱内容没有任务时段时，使用北京时间发布日期及 12:00 分界回退。展示所有已发布条目以保持汇总稳定，听过标记仍写入原历史系统。

## 发音处理

- 保留展示原稿；Radio 增加可选 `audio_script`，供编辑提交经过发音适配的独立朗读版本，省略时继续使用 script。
- Cortex 在合成输入和分段前保守转换百分数、GHz/MHz/kHz、毫秒、温度等单位，并将 CPU/GPU/USB/HTML/HTTP/HTTPS 独立缩写转换为规范中文全称；API、AI、LLM 等多义缩写留给编辑按来源语境处理。标准原名和不确定语义不做全局替换。
- 已更新共享 skill 的 `references/pronunciation.md`，要求结合语境处理多音字、核实专名、口语化符号和版本号、对照数字与否定词，并记录重点词抽听结果。Codex 与 Antigravity 安装目录均链接到同一份 repo skill。
- 当前 VoxCPM 没有经过验证的 SSML/音素接口；skill 与提交助手禁止把发音标签当作有效控制。不能承诺所有多音字和专有名词零误读。既有节目不自动重新合成，规则用于后续生成。
